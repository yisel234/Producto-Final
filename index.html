Visão Geral e Objetivos

Objetivo Geral

Este portfólio tem como objetivo apresentar o desenvolvimento de projetos práticos de robótica e eletrônica utilizando Arduino, explorando a aplicação do pensamento computacional e a resolução de problemas de engenharia.

Como a Ciência, Tecnologia e IA contribuem para a Visão?

A ciência dos materiais possibilita a criação de sensores ópticos e LEDs avançados, enquanto a tecnologia embarcada (como o Arduino) processa sinais do ambiente para automatizar tarefas visuais e de sinalização. A Inteligência Artificial eleva essa integração ao permitir que sistemas interpretem dados visuais em tempo real (visão computacional), auxiliando no reconhecimento de padrões, navegação de autônomos e no desenvolvimento de tecnologias assistivas para pessoas com deficiência visual.

Projetos de Robótica

Projeto 1: LED RGB Controlado por Potenciômetro

Objetivo: Controlar a variação de cores de um LED RGB dinamicamente de acordo com a leitura analógica de um potenciômetro.

Componentes Utilizados

  • 1x Placa Arduino Uno
  • 1x Potenciômetro de 10kΩ
  • 1x LED RGB (Anodo ou Cátodo Comum)
  • 3x Resistores de 220Ω
  • Protoboard e Jumpers

Mídia do Projeto

Relato de Erros e Soluções

Problema: As cores do LED piscavam de forma desordenada ao girar o potenciômetro.

Solução: Ajustou-se o mapeamento da leitura analógica (0 a 1023) para a saída PWM (0 a 255) utilizando a função map() do Arduino e estabilizou-se o terra (GND) no circuito.

Código Fonte (Arduino)

// Pinos do LED RGB e Potenciômetro
const int pinPot = A0;
const int pinRed = 9;
const int pinGreen = 10;
const int pinBlue = 11;

void setup() {
  pinMode(pinRed, OUTPUT);
  pinMode(pinGreen, OUTPUT);
  pinMode(pinBlue, OUTPUT);
}

void loop() {
  int valorPot = analogRead(pinPot);
  
  // Lógica simples de transição de cores por faixas
  if (valorPot < 341) {
    analogWrite(pinRed, map(valorPot, 0, 340, 255, 0));
    analogWrite(pinGreen, map(valorPot, 0, 340, 0, 255));
    analogWrite(pinBlue, 0);
  } else if (valorPot < 682) {
    analogWrite(pinRed, 0);
    analogWrite(pinGreen, map(valorPot, 341, 681, 255, 0));
    analogWrite(pinBlue, map(valorPot, 341, 681, 0, 255));
  } else {
    analogWrite(pinRed, map(valorPot, 682, 1023, 0, 255));
    analogWrite(pinGreen, 0);
    analogWrite(pinBlue, map(valorPot, 682, 1023, 255, 0));
  }
}

Ideia de Protótipo Acessível

Desenvolver um dispositivo assistivo de iluminação ajustável por toque ou voz para pessoas com baixa visão ou sensibilidade à luz (fotofobia), permitindo adaptar a temperatura de cor e o tom do ambiente de acordo com a necessidade do usuário.

Projeto 2: Sistema de Semáforo Duplo

Objetivo: Simular um cruzamento viário seguro sincronizando dois semáforos (Semáforo A e Semáforo B) com temporizações alternadas.

Componentes Utilizados

  • 1x Placa Arduino Uno
  • 2x LEDs Vermelhos, 2x LEDs Amarelos, 2x LEDs Verdes
  • 6x Resistores de 220Ω
  • Protoboard e Jumpers

Mídia do Projeto

Relato de Erros e Soluções

Problema: Ambos os semáforos ficavam abertos (verde) ao mesmo tempo em uma das etapas da transição.

Solução: Reorganizou-se a ordem dos comandos no código, utilizando variáveis de tempo consistentes para garantir que a transição de um semáforo para vermelho ocorra antes que o outro receba o sinal verde.

Código Fonte (Arduino)

// Semáforo 1
const int red1 = 2, yellow1 = 3, green1 = 4;
// Semáforo 2
const int red2 = 5, yellow2 = 6, green2 = 7;

void setup() {
  for(int i = 2; i <= 7; i++) {
    pinMode(i, OUTPUT);
  }
}

void loop() {
  // Estado 1: Semáforo 1 Verde / Semáforo 2 Vermelho
  digitalWrite(green1, HIGH); digitalWrite(red1, LOW);
  digitalWrite(red2, HIGH);   digitalWrite(green2, LOW);
  delay(5000);

  // Estado 2: Semáforo 1 Amarelo / Semáforo 2 Vermelho
  digitalWrite(green1, LOW);  digitalWrite(yellow1, HIGH);
  delay(2000);

  // Estado 3: Semáforo 1 Vermelho / Semáforo 2 Verde
  digitalWrite(yellow1, LOW); digitalWrite(red1, HIGH);
  digitalWrite(red2, LOW);    digitalWrite(green2, HIGH);
  delay(5000);

  // Estado 4: Semáforo 1 Vermelho / Semáforo 2 Amarelo
  digitalWrite(green2, LOW);  digitalWrite(yellow2, HIGH);
  delay(2000);
  
  digitalWrite(yellow2, LOW);
}

Ideia de Protótipo Acessível

Integrar um sinalizador sonoro (buzzer) com frequências distintas e vibração ao sistema de semáforo duplo, auxiliando pedestres cegos ou com baixa visão a identificarem com segurança o momento exato de travessia do cruzamento.
